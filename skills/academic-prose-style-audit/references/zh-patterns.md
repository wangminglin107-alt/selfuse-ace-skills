# Chinese Prose Finding Guide

| Pattern | Evidence needed | Default severity | Allowed response |
|---|---|---|---|
| Formulaic filler | Exact phrase and location | Warning | Delete or replace with substantive relation |
| Repeated paragraph opening | Three or more matching openings | Warning | Vary only after checking paragraph jobs |
| Connector stacking | Count plus local context | Advisory | Remove scaffolding that carries no logic |
| Uniform sentence rhythm | Document metric plus examples | Advisory | Vary syntax only where meaning remains clear |
| Repeated n-gram | Repeated sequence plus locations | Advisory | Inspect; revise only if genuinely formulaic |
| Missing protected anchor | Before/after exact comparison | Blocking | Reject revision and restore anchor |

High-frequency tokens are not automatically defects. `不是……而是……`, `不仅……而且……`, enumeration,
and explicit connectors remain valid when they express a real contrast, addition, or sequence. Flag
abuse in context rather than banning punctuation or syntax globally.
