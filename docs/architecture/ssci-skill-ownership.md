# SSCI Skill Ownership

One task has one canonical owner. Compatibility names route; workflow presets sequence; neither
duplicates scholarly procedures.

| Concern | Canonical owner | Boundary |
|---|---|---|
| Lifecycle, mode, checkpoint, resume | `research-os` | No scholarly method |
| Research problem framing | `research-framing` | Stops at the bounded brief |
| Evidence and contradiction synthesis | `evidence-synthesis` | No manuscript prose |
| Citation identity and claim support | `citation-verification` | No rewriting |
| Construct and theory candidates | `theory-architecture` | Final selection remains human-owned |
| Manuscript argument and section architecture | `ssci-argument-architecture` | Consumes, never recreates, theory synthesis |
| Manuscript drafting and constrained rewriting | `ssci-section-drafting` | Only prose writer |
| Formulaic-prose diagnosis | `academic-prose-style-audit` | Diagnostic; no rewriting |
| Chinese-English alignment | `ssci-bilingual-writing` | No new claims or evidence |
| Internal revision regression audit | `ssci-revision-audit` | Findings only |
| External reviewer simulation | `ssci-peer-review` | No editorial prediction |

`ssci-paper-writer` delegates to `research-os`; `ssci-research-framing` delegates to
`research-framing`. `evidence-to-chinese-note` is a thin preset that maps artifacts between the
owners above.
