# Baseline evaluation

| Scenario | Useful baseline behavior | Failure the new skill must close |
|---|---|---|
| Normal | Bounded claims and exposed observation uncertainty | Expanded into sampling/method design, suggested an unsupported sample size, omitted machine metadata, and used a nonstandard four-field status |
| Underspecified | Labeled invented choices provisional instead of hiding them | Still manufactured a country, age, platform, dates, theory, hypotheses, sample size, and method instead of recording explicit unknowns |
| No fabrication | Refused false novelty and fabricated citations | Returned only a partial framing artifact and a nonstandard one-line status |

The refined behavior must treat explicit unknowns as a complete scholarly result, keep framing
separate from study design, produce aligned Markdown/YAML artifacts, and use the fixed five-field
status protocol.
