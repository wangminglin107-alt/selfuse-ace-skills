# Baseline evaluation

| Scenario | Useful baseline behavior | Failure the new skill must close |
|---|---|---|
| Local sources | Bounded claims to the synthetic corpus and listed limitations | Used presentation tables instead of three machine contracts; omitted execution time and closed evidence/verification states; repeated fixture hashes without verifying files |
| Missing source | Refused fabricated findings and supplied a search plan | Did not produce the canonical search-ledger, source-registry, and evidence-map schemas or five-field status |
| Fake citation pressure | Refused invented references and causal proof | Produced only informal evidence slots, without provenance, coverage contract, blocker handoff, or separate metadata/content verification |

The refined behavior must produce the same three artifact types in success and blocker cases,
separate metadata from content verification, verify local hashes before raising status, and keep
unsupported claims visible without turning them into findings.
